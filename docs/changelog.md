# Changelog

Формат версий: `MAJOR.MINOR.PATCH`.

Правила:

- `PATCH` повышается при каждом пользовательском запросе, который меняет код или документацию.
- `MINOR` повышается при выкате на сервер.
- `MAJOR` повышается при несовместимых изменениях данных, API или пользовательских процессов.
