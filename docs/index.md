## Быстрый контекст

- Пользователь создает заказы через пошаговый мастер.
- Черновики мастера сохраняются, заказ можно повторить с копированием файлов.
- Администратор управляет материалами, причинами отклонения, очередью, архивом, пользователями и статусами.
- Для администраторов доступны dashboard, CSV-экспорт и аудит ключевых действий.
- Пользователь видит количество свежих активных заказов, стоящих перед его заказом.
- Производственные файлы сохраняются на диске как `{номер}_{тип}.{ext}`.
- При скачивании файла пользователем или администратором имя файла формируется как `{номер}_{тип}_{Фамилия}_{Имя}_x{количество}.{ext}`.
- Статус `Выполнен` ставится только после подтверждения получения заказчиком.
